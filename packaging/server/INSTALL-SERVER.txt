LanePulse server for Ubuntu and Red Hat (x86_64, NVIDIA GPU)
============================================================

The full guide, with every step from a new server to daily use, is the PDF "LanePulse server installation guide".
This is the short version.

Needs: Ubuntu Server 22.04 or 24.04, or Red Hat Enterprise Linux 8 or 9 (also Rocky Linux and AlmaLinux), an NVIDIA
GPU with its driver (see server.json for the oldest driver version), and an ordinary user account. No root and no
sudo are needed. Nothing is downloaded during install. LanePulse brings its own Python and never uses or changes
the system Python.

Install or update (no root: type these as yourself)
    tar -xzf lanepulse-server-<version>-linux-x86_64.tar.gz
    cd lanepulse-server-<version>-linux-x86_64
    ./install-server.sh
  It checks every file, installs into ~/lanepulse (program, data, backups and models), runs a small offline check,
  backs up the data (on an update), then starts LanePulse. It starts by itself whenever the server boots, and again
  if it stops (systemd for your user, or cron where that is not allowed). The lanepulse command is set up for you.
  Options: --data DIR (default ~/lanepulse/data), --backups DIR, --models DIR, --port N (default 8765),
           --allow-from CIDR (default: this server's local network; "any" for every address).
  What still needs the server's administrator (once, and only if missing): the NVIDIA driver, and opening port 8765
  in the firewall when other computers cannot reach it (the installer prints the exact command to ask for).

  As a system service instead (an administrator, optional): sudo ./install-server.sh installs into /opt/lanepulse,
  with data in /srv/lanepulse, its own service account, and the firewall opened. Commands that change it then need
  sudo (sudo lanepulse restart, ...). Red Hat: keep SELinux enforcing and firewalld on; the installer labels
  LanePulse's files for SELinux and opens the port in firewalld (ufw on Ubuntu). The NVIDIA driver steps for Red Hat
  are in the PDF guide, section 18.

Open it from other computers:  http://<server address>:8765
  The browser asks once for the password, which the installer prints at the end. Choose your own in LanePulse:
  the key icon at the top right (it needs the current one). Forgotten? On the server: lanepulse password
  sets a new one (it asks twice). lanepulse password --show prints the one from install until you change it.
  Open it by the server's IP address, or by its own name; to use another DNS name, add it to
  TWB_ALLOWED_HOSTS="name1,name2" in ~/lanepulse/lanepulse.conf (system service: /etc/lanepulse/lanepulse.conf).

Training:   on a mission's Learning tab, "Train a new vehicle detector here". It runs on the GPU; PyTorch is
            included, so nothing needs setting up or downloading.
Daily use:  lanepulse help    (status, logs, restart, import-model, backup, speed-check, rollback, train)
Settings:   ~/lanepulse/lanepulse.conf, then lanepulse restart
Remove:     lanepulse uninstall   (data, backups and models are kept)
