LanePulse for Mac (Apple silicon: M1 to M5)
==========================================

Install
1. Drag LanePulse onto the Applications folder in this window.
2. Open Applications and double-click LanePulse.
3. The first time, a Terminal window opens and LanePulse sets itself up from the internet: its own Python, PyTorch,
   the other packages and the models (about 2 GB; a few minutes on a fast connection). Keep the window open. When it
   is done, LanePulse opens in your browser at http://127.0.0.1:8765. From then on it runs without the internet.
   No administrator rights are needed, and no other Python on the Mac is used or changed. Every file it downloads
   is checked against the exact file this version was tested with. If the setup stops (for example the internet
   drops), open LanePulse again: it continues from where it stopped.

The first time, macOS may say it cannot check LanePulse for malicious software, because the app is not signed with
an Apple developer account. To allow it, once:
- Open System Settings > Privacy & Security, scroll down to "LanePulse was blocked" and press Open Anyway.
- Or, in Terminal:   xattr -dr com.apple.quarantine /Applications/LanePulse.app

Where things are
- Everything LanePulse keeps is in the LanePulse folder in your home folder:
    data      missions, results and evidence
    backups   the nightly backup (02:00)
    models    the detector models, including trained ones you import
    logs      server.log, setup.log
    runtime   the Python and packages LanePulse runs on (set up by the app)
- Your source images and videos are only read, never moved.

Use
- Opening LanePulse starts it if it is not running, then opens the browser. It keeps running in the background
  after you close the browser tab; open LanePulse again to get back to it.
- To stop it: double-click "Stop LanePulse.command" in the LanePulse folder. Processing stops at once and continues
  from where it stopped the next time.
- To train the vehicle detector on your own reviewed images: a mission's Learning tab, "Train a new vehicle detector
  here". It uses the Mac's GPU. Details: TRAINING.txt in the LanePulse source, or the learning page itself.
- To add a model trained elsewhere: double-click "Import Model.command" in the LanePulse folder and drag the .zip into the
  window. Then evaluate it on the learning page and promote it if it is better.

Update
- Drag the new LanePulse onto Applications and replace the old one, then open it. It needs the internet once more
  to update its runtime (usually only LanePulse itself is downloaded again; the models are kept). Your data and models are kept; an older version
  that is still running is stopped and the new one starts. The .dmg can be deleted afterwards.

Remove
- Stop LanePulse, then drag it from Applications to the Bin. The LanePulse folder with your data stays until you
  delete it yourself (its runtime folder, about 3 GB, can be deleted at once).
